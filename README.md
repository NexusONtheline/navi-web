# NAVI · web

La página de [NAVI](https://github.com/NexusONtheline/navi) (Linux) y [NAVI TV](https://github.com/NexusONtheline/navi-tv) (Google TV).

👉 **https://nexusontheline.github.io/navi-web/**

HTML, CSS y JavaScript sin dependencias. NAVI hace de guía: se pasea por la página, te explica cada sección, te sigue con la mirada, a veces estira la manita para tocar tu cursor y se duerme con gorrito si no te mueves. Abajo hay una terminal de mentira para hablarle.

Para verla en tu PC: `python3 -m http.server` en esta carpeta y abre http://localhost:8000.
